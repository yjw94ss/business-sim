# 生意人 · 经营模拟器

一个在浏览器里跑的**商业决策训练沙盘**：24 个月，从一家小店做到一家公司。

不是数值点击器 —— 每一轮你都要在价格、库存、产能、现金之间做取舍，而系统会用真实的商业逻辑给你算账。

**在线试玩：** https://yjw94ss.github.io/business-sim/

---

## 为什么它不一样

大多数经营游戏的问题是：随便点都能赢，赢完学不到东西。这个沙盘反过来 ——
它把**边际收益递减、价格弹性、产能天花板、现金流与利润的分离**做成硬约束，
让"凭直觉做"和"算清楚再做"产生肉眼可见的差距。

三条路径的真实实测（同一局，24 个月，起始净资产 ¥65,368）：

| 玩法 | 期末净资产 | 累计回报 | 评级 |
|---|---|---|---|
| 被动：默认定价 + 按需求订货 + 不投资 | ¥229,060 | +250% | 掌柜 |
| 专业：逐月优化三档定价，但不投资 | ¥492,739 | +654% | 大商 |
| 增长：优化定价 + 持续营销 + 三级门店扩张 + 杠杆 | ¥611,519 | +836% | 商业巨擘 |

**同一个开局，决策差异带来 2.7 倍的终局差距。**

## 你在每一轮要做的四个决策

### 1. 定价 —— 每件商品的弹性不一样

| 商品 | 定位 | 进价 | 参考价 | 需求弹性 |
|---|---|---|---|---|
| 基础款 | 引流品 | ¥16 | ¥34 | 1.90（极敏感） |
| 升级款 | 主力品 | ¥44 | ¥95 | 1.70（中等） |
| 旗舰款 | 利润品 | ¥104 | ¥260 | 1.55（不敏感） |

需求的定价响应是 `Q = base × (P / 参考价)^(-弹性)`：

- 基础款提价 10%，销量掉约 17% —— **引流品不能涨价**；
- 旗舰款提价 10%，销量只掉约 14%，而每件多赚 26 元 —— **利润品该敢涨**；
- 三档的最优价分别在 ¥34 / ¥107 / ¥293 附近，参考价只是市场锚点，不是答案。

### 2. 订货 —— 库存是负债，不是资产

- 库存每月吃 **1.5% 的持有成本**（资金占用 + 仓储）
- 缺货直接砸**口碑**，口碑又会拉低后续所有月份的需求
- 进货时现金立刻流出，但只有**卖掉的货**才计入成本（COGS）—— 这是利润与现金分家的根源

### 3. 营销 —— 边际收益递减是铁律

```
需求倍数 = 1 + 0.28 × log₂(1 + 有效投入 / 3000)
营销有 40% 的跨月留存（品牌不是一次性的）
```

投 ¥3,000 带来约 +28% 需求，投 ¥12,000 只带来约 +65%。
**当 ROI < 1 时，营销就在净亏损** —— 报告里会直接给你算出来。

### 4. 产能与资本 —— 没有产能的营销是浪费

- 每名员工 ¥3,200/月，产能 250 单
- 产能打满时砸营销，钱花了、单接不了，回报为零
- 门店升级：¥12,000 / ¥26,000 / ¥44,000，每级 +22% 客流、+80 产能、+¥400 月租
- 借款月息 1.2%，上限 ¥150,000；现金穿仓会自动高息补足，补不上就**出局**

## 它教你的六件事

1. **毛利 = (售价 − 进价) × 销量** —— 降价换量，未必换钱
2. **产能是天花板** —— 利用率 > 95% 时，该招人而不是加营销
3. **营销边际递减** —— 看 ROI，不看增量
4. **利润 ≠ 现金** —— 企业死于现金流，不死于亏损
5. **库存是负债** —— 周转越快，同样的钱赚更多次
6. **杠杆双向放大** —— 增量回报必须高于资金成本

结局面板会做一次完整复盘：指出你全程最大的隐性亏损（缺货损失了多少单）、
毛利率是否健康、营销占比是否已经变成"买流量维持增长"，
并解释**为什么累计净利和净资产增长对不上**（资本支出不进利润表）。

## 玩法

打开网页即开局，无需安装、无后端、无依赖。

- 每月调整定价 / 订货量 / 营销 / 员工数，点「结算本月」
- 左侧「预计需求」「预计毛利」会随输入实时重算，可以先把方案试算清楚再结算
- 随机事件（供应商提价、网红探店、竞品降价、合规抽检……）需要你当场做取舍
- 24 个月后按期末净资产评级：街边学徒 → 小老板 → 掌柜 → 商人 → 大商 → 商业巨擘

支持手机端（决策表会自动转成卡片式布局）。

## 技术

单文件 `index.html`，原生 HTML/CSS/JS，零依赖、离线可用。
图表用 Canvas 手绘。所有数值模型（需求函数、产能分配、利润表、现金流）都在页面内实时计算。
